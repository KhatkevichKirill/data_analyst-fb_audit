# Data Analyst Knowledge Base

This starter kit includes a small, generic knowledge base for the `read_wiki` tool.

Pages:
- `readme` — this overview
- `onboarding` — how to think about the demo warehouse
- `reference` — example queries and footguns
- `schema` — table catalog
- `weekly_playbook` — recurring weekly checks

Replace or extend these files with your own schema documentation when you connect a real warehouse.
